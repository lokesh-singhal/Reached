Reached is a full-stack stay booking platform that connects guests with hosts and unique listings.

## Live App

Visit the deployed app: [reached-nine.vercel.app](https://reached-nine.vercel.app/)

For the best viewing experience, open the app in Chrome and set the browser zoom to **80%**.

## Features

### For guests

- Browse and search available properties.
- Filter listings and explore locations on an interactive map.
- View photos, availability, pricing, and reviews.
- Select dates and guests, then complete bookings with Razorpay payments.
- Manage reservations, favourites, profile details, and personal reviews.

### For hosts

- Create, edit, and manage property listings.
- Upload listing images and configure amenities, pricing, and details.
- Manage availability with a booking calendar.
- View reservations, dashboard statistics, and earnings.
- Read and filter guest reviews.

## Tech Stack

- Next.js and React with TypeScript
- MongoDB with Mongoose
- Better Auth authentication
- Razorpay payments
- Cloudinary image uploads
- Leaflet maps and Recharts analytics

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
